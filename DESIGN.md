# Math Quest learning design (Pre-KG to Class 4)

Status: Class 1 has the skill tree, mastery gate, Fix-it rounds, fun activities and Olympiad Challenge (v6). Pre-School and Classes 2-4 still use simple lists. Stage 2 and 3 below are still to do.

## Idea: strong basics, then deep thinking
Teach the way strong problem-solvers think, in kid-sized steps. No claim to copy any university or exam.

1. **First principles.** Every rule is built from a picture or object first (why 7 x 8 = 8 x 7, why we carry).
2. **Prerequisite skill tree.** Advanced topics unlock only when the basics under them are mastered (about 80% first-try over the last 10 answers).
3. **Find the pattern.** Each topic has "what do you notice?" questions before the rule is shown.
4. **Estimate first.** "About how many?" before exact answers. Builds number sense.
5. **Many ways, one answer.** Show 2 ways to solve (count, group, draw). Reward understanding, not speed.
6. **Break it down.** Hard problems are split into small steps the child can tap through.
7. **Mistake is a clue.** Wrong answers get a hint and a mini-lesson, never a penalty.
8. **Spaced review.** Mastered basics return weekly.
9. **Stretch ladder per topic.** Basic > Challenge > Olympiad-style.
10. **Parent skill map.** Green mastered, yellow practising, grey not started.

## Levels
Pre-KG/LKG/UKG (pictures, sounds), Class 1-2 (pictures + short words), Class 3-4 (short sentences, tables, division, fractions, logic).

## Build stages
1. Skill-tree engine, level picker, Pre-KG to Class 1.
2. Class 2 to 4.
3. Olympiad stretch ladder and per-class mock tests.
